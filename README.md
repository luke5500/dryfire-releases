# dryfire releases

Public update bundles for dryfire target modules. Units check `latest.json`
daily and offer one-click installs from their setup page — bundles are
Ed25519-signed and every unit verifies the signature before installing, so
this repo being public is safe by design.

Manual install: download the newest `dryfire-update-X.Y.Z.zip` from
Releases, then any module's setup page -> Software update -> choose the file.
